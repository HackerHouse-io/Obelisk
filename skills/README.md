# Built-in skill catalog

Each subdirectory is one skill, with a `SKILL.md` that the prompt compiler attaches to runs of agents that reference it. Per-repo overrides at `<user-repo>/skills/<name>/SKILL.md` win over these built-ins.

The skills below are short, opinionated playbooks distilled from senior-engineer practice. The intent is to vendor [`addyosmani/agent-skills`](https://github.com/addyosmani/agent-skills) wholesale; until that swap, these stubs hold the contract.
